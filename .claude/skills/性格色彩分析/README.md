## ✨ 特性

- **行为 → 动机 → 色彩**：穿透行为表象，分析深层动机

- **多来源验证**：检查行为在不同材料中是否一致
- **不共存铁律**：检验色彩组合的逻辑自洽性
- **人际动态**：分析与其他性格的相处模式

## 📋 分析方法论

### 核心概念

| 概念 | 定义 | 能否改变 |
|------|------|----------|
| **性格（本色）** | 先天、与生俱来的核心动机 | ❌ 无法改变 |
| **个性（修饰）** | 后天环境塑造的行为模式 | ✅ 可以训练 |

### 行为 → 动机 → 色彩

| 观察到的行为 | 追问动机 | 可能的色彩 |
|--------------|----------|------------|
| 总是帮助陌生人 | "为什么？" | 红色(快乐助人) / 绿色(天性善良) |
| 迟到但无所谓 | "为什么？" | 红色(忘记) / 绿色(不在乎) |
| 坚持要按自己方式做 | "为什么？" | 黄色(控制) / 蓝色(完美) |
| 遇到问题先思考再行动 | "为什么？" | 蓝色(理性) / 绿色(回避) |
| 承担多个职位 | "为什么？" | 黄色(成就) / 红色(社交) |

### 不共存规则

| 组合 | 诊断结论 |
|------|----------|
| 强红 + 强蓝 | 必有后天修饰（红蓝不共存） |
| 强黄 + 强绿 | 必有后天修饰（黄绿不共存） |

### 四色特征速查

#### 🔴 红色（快乐）
- **优势**：外向、感性、善于社交、调动气氛
- **过当**：话唠、冲动、三分钟热度、不兑现承诺

#### 🔵 蓝色（完美）
- **优势**：内向、理性、深刻、思考独立
- **过当**：悲观、敏感、记仇、拖延

#### 🟡 黄色（控制）
- **优势**：外向、目标导向、果断、自信
- **过当**：霸道、自负、不认错、报复心强

#### 🟢 绿色（稳定）
- **优势**：内向、平和、宽容、耐心
- **过当**：软弱、逃避、没主见

## 📖 分析流程

### Step 1: 素材通读
- 快速浏览所有材料，建立整体印象
- 列出所有文件名，标记关键段落

### Step 2: 行为提取
对每个材料提取：
- **情境**：什么场景/时间
- **行为**：具体做了什么
- **结果**：带来什么

### Step 3: 动机追问
对每个行为追问："TA 为什么这样做？"

### Step 4: 多来源验证
- 出现 ≥2 次 → 可信度"高"
- 仅出现 1 次 → 可信度"单源"
- 矛盾 → 标注"需进一步分析"

### Step 5: 先天/后天分离
- **先天性格**：跨情境一致、反复出现
- **后天个性**：特定环境、特定角色

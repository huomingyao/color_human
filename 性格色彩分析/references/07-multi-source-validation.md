# 多来源验证指南

## 目的

验证分析结论的可信度，通过检查同一行为/动机是否在多个材料中出现。

## 验证规则

### 1. 出现次数 → 可信度

| 出现次数 | 可信度评级 | 说明 |
|---------|-----------|------|
| ≥3 次 | **高** | 多重印证，结论可靠 |
| 2 次 | **中** | 有一定证据支撑 |
| 1 次 | **低** | 单源证据，需谨慎 |
| 矛盾 | **需分析** | 不同材料中矛盾！ |

### 2. 行为模式匹配

判断是否为"同一行为"的近似表达：

| 例子 | 是否同一行为 |
|------|-------------|
| "被打发去打杂" + "做善后工作" | ✓ 是（都是辅助角色） |
| "人际交往困难" + "交流前需心理准备" | ✓ 是（社交焦虑） |
| "想成为领袖" + "担任班长" | ✓ 是（追求成就） |

### 3. 来源文件级别

| 级别 | 来源类型 | 权重 |
|------|---------|------|
| 1 | 本人的自我分析/反思 | 高 |
| 2 | 具体行为描述（作业、周总） | 高 |
| 3 | 他人评价 | 中 |
| 4 | 推测/推断 | 低 |

## 示例：火铭遥分析

```
同一行为：社交焦虑
- 来源1：期中总结 "对于人际交往十分困难"（本人自我描述）
- 来源2：期中总结 "每次交流前需心理准备"（本人描述）
→ 出现2次 → 可信度：中
```

## 输出格式

```markdown
### 4. 多来源验证
| 核心模式 | 出现次数 | 可信度 | 来源文件 |
|---------|---------|--------|---------|
| 社交退缩 | 2 | 中 | 期中总结、周总 |
| 认真负责 | 3 | 高 | 申请信、期中总结、周总 |
| 目标导向 | 1 | 低 | 申请信 |
```

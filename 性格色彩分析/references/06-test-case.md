# 测试案例：蔡岩峻性格色彩分析

## 原始材料

### 申请信 (2023.5.22)
- 主动放弃体制，选择新教育
- 担任班长、在野党、剧本负责人
- 自我评价：负责任、愿意改变、大度、体育好
- 缺点：同理心不足、表达不清、思维散乱

### 入职问卷 (2024.6)
- "我不是为别人而活，而是为自己而活"
- 担任班长、组长、多项活动负责人
- "追求领袖性格：沉稳、细心、胆识、担当、诚信、大度、积极"
- 每天记录同学问题，思考解决方案
- "在沉稳和细心上欠缺，正在弥补"

---

## 分析过程

### Step 1: 行为提取

| 行为 | 场景 | 动机分析 |
|------|------|----------|
| 毅然放弃体制读新教育 | 人生选择 | 追求自我价值，目标明确 |
| 多次担任班长/组长 | 学校 | 承担责任，追求成就 |
| 记录同学问题并解决 | 管理者 | 追求完美，不断改进 |
| "为自己而活" | 价值观 | 自我导向，非他人驱动 |
| "看到不完美的自己" | 反思 | 追求成长，修正自我 |
| "愿意改变" | 自我评价 | 追求进步 |
| 原则性强，严苛 | 班长评价 | 追求规则和秩序 |
| 负责，投入 | 工作态度 | 目标导向，使命必达 |

### Step 2: 动机归类

| 动机 | 对应色彩 | 行为数 |
|------|----------|--------|
| 快乐（享受过程） | 红色 | 0 |
| 完美（不断改进） | 蓝色 | 4 |
| 控制（目标导向） | 黄色 | 4 |
| 稳定（避免冲突） | 绿色 | 0 |

### Step 3: 色彩判定

- **主导色彩：黄色**（控制动机最强）
  - 行为："毅然决定"、"承担责任"、"使命必达"
  - 特征：目标导向、行动力强、追求成就

- **辅助色彩：蓝色**（完美动机次强）
  - 行为："愿意改变"、"记录问题"、"看到不完美的自己"
  - 特征：追求成长、深思熟虑、原则性强

### Step 4: 先天/后天区分

| 类型 | 内容 | 判定 |
|------|------|------|
| 先天 | 目标导向强、行动力强、承担责任 | 黄色本色 |
| 先天 | 追求进步、原则性强 | 蓝色本色 |
| 后天 | "沉稳、细心"的刻意训练 | 环境塑造 |
| 后天 | 对"大度"的理解（接纳他人想法） | 教育习得 |

### Step 5: 画像输出

```markdown
## 性格色彩分析报告：蔡岩峻

### 1. 色彩判定
- 主导色彩：**黄色**
- 辅助色彩：**蓝色**
- 置信度：**高**
- 不共存检验：✓ 通过（黄+蓝兼容）

### 2. 先天性格（本色）
- 核心动机：控制 + 成就
- 自然倾向：
  - 目标明确，行动力强
  - 主动承担责任，追求领导角色
  - 追求不断进步和自我超越

### 3. 后天个性（修饰）
- 环境因素：新教育体系、班级管理实践
- 习得行为：
  - 蓝色式的反思习惯
  - 对"领袖性格"的刻意训练

### 4. 优势与过当
- 优势：目标导向强、责任感强、持续成长
- 过当风险：可能过于严苛、忽视他人感受

### 5. 人际动态
- 最佳搭配：蓝色（共同追求进步）+ 绿色（需要绿的宽容）
- 注意：与红色可能冲突（控制 vs 自由）
```

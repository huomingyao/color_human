## 使用方式

每个 skill 目录下都有独立的 `SKILL.md`，记载了该技能的完整使用方法。

### 快速开始

```bash
# 查看技能列表
ls skills/

# 进入特定技能
cd skills/[skill-name]/
```

---

## 添加新 Skill

1. 在 `skills/` 下创建新目录
2. 添加 `SKILL.md`（遵循 skill 元数据格式）
3. 添加 `references/` 参考资料
4. 更新本 README
